# Book Management System API

RESTful backend service for cataloging, inventory management, and author-book associations.

## Features
- Book catalog management with full CRUD operations.
- Relational mapping between authors, categories, and inventory items.
- MySQL persistence with Spring Data JPA.

## Tech Stack
- Java 21 LTS
- Spring Boot, Spring Data JPA
- MySQL 8.0
- Maven Wrapper

## Getting Started
```bash
./mvnw clean compile
./mvnw spring-boot:run
```
